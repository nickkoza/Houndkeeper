For CAD work, such as designing the arm mount and bin, and for the sims. Units and frames are stated per file; nothing here
is modified from its source except the assembled exports.

The printed mount's own parts (adapter, module, bench plate, bin, hat seat) are in `cad/mount/print/` as STEP (this
frame, with the origin at the body centre) and 3MF (on the bed). Its base seat is 36 mm above the body top used here
(`maker_arm.mount_plate_m`), as in the sims.

## Importing into Fusion
Insert > Insert Mesh, pick the STL, set **Units: Millimeter**. Meshes are visual meshes (triangles), fine as references
to design around; convert to a solid only if you need to cut against them (Mesh > Convert Mesh), which can be slow for
the full Go2. For the arm's mounting holes, the base-only file is the one to measure from.

Regenerate the exports with `python tools/export_models.py` (DimOS venv).

## Scanned items (`items/gso/`, not in git)
The sims' toys and household clutter are real scanned objects, about 3 MB each, so they are fetched rather than
committed. To populate or refresh them (identical models on every machine: the source commit is pinned):

    tools/fetch_items.sh

It reads the item list from `sim/arm/items.py`, so adding an item there and re-running the script is all a new item
needs. It needs git and a Python with numpy, mujoco and Pillow (the DimOS venv by default; override with `PY=...`).
